# Getting Started

This page helps first-time visitors use the project quickly.

## Prerequisites

- A GitHub account
- Git installed on your machine
- Python 3.10+ installed

## Step-by-Step

1. Open the repo: <https://github.com/dkupratis-debug/FlaskAppEnhanced>
2. Read `README.md`.
3. Open `docs/START_HERE.md`.
4. Follow `docs/FIRST_10_MINUTES.md`.
5. Pick one task from `docs/PRACTICE_EXAMPLES.md`.
6. Make a small change on a new branch.
7. Open a pull request.
8. Wait for CI checks to pass.

## What You Should Expect

- CI checks for lint, tests, markdown, yaml, and links.
- Review feedback if your change needs improvement.
- Merge after checks and review requirements are satisfied.
